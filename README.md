##  Descripción General del Sistema
Este proyecto es un sistema de gestión por consola para una biblioteca, desarrollado en Python. Permite administrar el registro de usuarios mediante validación de DNI, gestionar préstamos de libros verificando disponibilidad, y procesar devoluciones con cálculo automático de multas por atraso. El sistema utiliza listas, diccionarios, variables globales y un menú interactivo basado en estructuras de control repetitivas y condicionales. Además, genera estadísticas y las exporta a un archivo de texto plano (.txt).

##  Instrucciones de Ejecución
1. Tener instalado Python (versión 3.x) en la computadora.
2. Descargar o clonar este repositorio.
3. Abrir una terminal o consola de comandos en la carpeta del proyecto.
4. Seguir las instrucciones del menú interactivo en pantalla.
